# 📝 Interactive To-Do List Web Application

A **dynamic and responsive To-Do List web application** built using **HTML, CSS, and JavaScript** with advanced features including **task management, localStorage persistence, filters, edit functionality, and dark mode**.

---

## 🔹 Features

- **Add, Edit & Delete Tasks** – Create new tasks, modify existing tasks by double-clicking, and remove tasks individually.  
- **Mark as Completed** – Tasks can be marked completed using checkboxes with visual indicators like strikethrough and opacity.  
- **Filter Tasks** – View tasks by **All, Pending, or Completed** status.  
- **Persistent Storage** – All tasks and their statuses persist across browser sessions.  
- **Responsive Design** – Fully responsive layout for desktop and mobile devices.  
- **Smooth Animations** – Animated task additions and hover effects for a modern interactive experience.

---

## 💻 Technologies Used

- **HTML5** – Structure and layout  
- **CSS3** – Flexbox, Gradients, Animations, Responsive design  
- **JavaScript** – DOM manipulation, Event handling  
- **localStorage** – Persistent task storage in the browser
